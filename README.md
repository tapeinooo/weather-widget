# たぺいの天気（weather-widget）

気象庁の予報を数日分並べて見せる、自分用の Android ホーム画面ウィジェット。

## 入れ方・更新

- 最初は Releases の最新の APK（`weather-widget-v2.0.<番号>.apk`）をスマホで開いて入れる。
- そのあとは、アプリを開いて「更新を確認」で新しい版を入れる（開いたときに新しい版があれば知らせが出る）。
- main に変更が入るたびに GitHub Actions が APK を作って Releases に出す（版の番号は自動）。

## 通信

- 予報・場所の検索：気象庁・国土地理院
- アプリの更新：GitHub の Releases
